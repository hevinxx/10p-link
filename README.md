# 10p-link

인스타그램 프로필(@10p.read) 링크용 안내 페이지. 예전 Firebase Dynamic Links(`10p.page.link/NLtk`)를 대체한다.

- iPhone·Android에서 열면 App Store / Google Play로 바로 이동한다.
- PC 등 그 밖의 환경에서는 두 스토어 버튼이 있는 안내 페이지가 보인다(`?stay`를 붙이면 휴대폰에서도 이동 없이 페이지를 볼 수 있다).
- GitHub Pages(master 루트)로 게시: https://hevinxx.github.io/10p-link/
